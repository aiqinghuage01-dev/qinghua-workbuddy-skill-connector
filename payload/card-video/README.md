# 卡片视频-学员版 2.1.0

在 WorkBuddy 中把已确定的文案制作成卡片动画视频。默认 1080×1920；支持免费在线配音及配置自己的 MiniMax 音色。

导入完整技能 ZIP 后，对 WorkBuddy 说：

> 检查并初始化卡片视频环境，生成一条安装测试片，告诉我哪些检查通过了。

随后提供你的文案，并说“把这段文案做成卡片视频”。首次使用可能需要下载运行组件。若缺少基础 Python，可通过 WorkBuddy 自带运行环境检测安装，后续依赖由本包的初始化脚本管理。

详见 references/WorkBuddy安装与使用.md；实际支持验证状态见 references/平台验收记录.md。测试片使用合成音轨；不冒充配音服务测试。

本包不含个人密钥、历史文案、头像、声音样本和成片。下载的第三方依赖依其各自许可证使用；Noto 字体的许可证随包保留。
