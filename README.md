# 清华哥技能助手（WorkBuddy 本地连接器）

在 WorkBuddy 中通过自然语言检查、安装、修复和使用卡片视频学员版。当前版本 0.1.0 为测试版，首版只包含卡片视频 2.1.0，不把其他尚未迁移的技能列为已支持。

## 使用

安装连接器后说“帮我检查卡片视频环境”。缺依赖时说“初始化卡片视频环境”，它会返回后台任务编号。等待任务真实完成，再说“生成安装测试片”。文案确定后可说“把这段文案做成卡片视频”。

WorkBuddy 负责准备 Node 20。本连接器会复用 WorkBuddy 的 Python，缺失时下载固定版本、SHA256 校验的便携 Python；技能代码和依赖存于用户的 `~/.qinghua-skills`，每条成片有独立目录。无需管理员安装，无需服务器，无需购买本连接器的配音账号。

需 WorkBuddy >=5.0.0，网络可访问发布包、Python 安装包、npm、PyPI 及浏览器下载服务。首次初始化需要下载运行环境，不保证所有网络都能连接。免费在线配音同样依赖第三方服务可达。

## 能力与边界

- 9 个工具：技能列表、只读环境检查、初始化、修复、安装测试片、任务状态、近期任务、使用说明、卡片视频制作。
- 固定版本与哈希校验；重复安装可复用已有环境。修复会恢复固定版本代码和字体，保留 `.env`、运行环境和已有成片。
- 测试片使用合成测试音轨，不调用付费 API，也不代表在线配音已经可用。
- 正式视频使用免费在线配音，文本会发送给在线配音服务；视频和工程留在本机。本版不提供收费配音、数字人平台或个人飞书发送入口。
- 通过连接器工具使用；没有声称把这些文件自动注册到 WorkBuddy 独立技能库。
- 支持代码：Mac Apple Silicon、Intel Mac、Windows x64、Linux x64/arm64。实机验收状态以 `docs/验收记录.md` 为准；未实测系统不承诺已验证。
- 无需账户授权；不读取用户其他应用凭据，不附带清华哥头像、声音样本、历史视频和密钥。

## 维护

后台任务使用落盘记录，重启 WorkBuddy 后可查询。`queued` / `running` 只是开始执行，不代表安装完成。只有 `completed` 且复验通过才能说成功。失败时保留可读日志；不跳过哈希校验，不盲删活动进程的锁。进程树无法确认清理时阻止后续任务，提示处理。

第三方组件与许可见 THIRD-PARTY-NOTICES.md。Remotion 许可适用于实际渲染，不能把本连接器许可当成第三方组件许可。
