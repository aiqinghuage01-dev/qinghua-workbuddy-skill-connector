# WorkBuddy 本地技能连接器

用户 2026-10-03 授权设计并直接提交 WorkBuddy 连接器。

采用本地 stdio MCP + Skill，WorkBuddy 声明 Node 20 运行时，自动准备独立 Python（复用 WorkBuddy/PATH，缺失时校验下载便携版本）；无需服务器。首版仅支持已验收的卡片视频学员包。

实施：SDK 固定版本打包 → 白名单复用学员包 → 安装与诊断隔离运行 → 长任务 job 状态 → 固定 source、版本和图标 → 本地协议及实际安装/测试片验收 → 导出公共安装包、不可变下载地址 → 官方后台上传与提交 → 记录平台真实状态。

能力边界：不含本人的原片、头像、克隆声音、API密钥。Windows/Intel Mac 可支持的代码与真实验收分别记录，未实测不写已验证。授权若遇到浏览器登录/自动化权限由用户完成。
